# E-commerce Sales Analysis for Business Growth

This repository contains a complete Data Analysis project where customer 
data is analyzed to extract meaningful insights such as customer behavior,
spending patterns, membership trends, and engagement metrics. The analysis 
is performed using Python and popular data science libraries.

### Problem Statement :

E-commerce businesses collect large amounts of sales and customer data
but often fail to use it effectively. As a result, they miss opportunities to
identify top products, understand customer behavior, and optimize pricing
and marketing strategies.

This project aims to analyze e-commerce sales data to extract actionable
insights that can help improve revenue, customer satisfaction, and overall
business performance.

## Dataset Source :

E-Commerce Customer Behavior & Sales 2020–2026

Collected from : [Kaggle](https://www.kaggle.com/datasets/meruvakodandasuraj/e-commerce-customer-behavior-and-sales-20202026/data?select=customers.csv)

## Objectives of the Analysis :

- Explore and understand customer  datasets
- Perform data cleaning and preprocessing
- Analyze customer spending and order patterns
- Identify repeat customers and engagement behavior
- Visualize key findings using charts and graphs
- Generate business insights from data

## Tools / Technologies to be Used :
- Programming Language: Python
- Libraries:
    - NumPy
    - Pandas
    - Matplotlib
- Environment: Google co lab

## Dataset Description

### customers.csv

Contains customer-related information such as:

- Customer ID
- Country
- Age
- Gender
- Membership tier
- Registration date
- Total orders and spending
- Review score
- Preferred device & payment method
